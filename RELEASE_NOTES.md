# Release Notes — XuxuBank v1.2.0 🌵💰

Esta versão marca a transformação do XuxuBank para o sistema de design **"The Modern Sertão"**, unindo a sofisticação editorial com as raízes culturais do Nordeste.

## 🚀 O que há de novo

### 🎨 Design System "Modern Sertão"
- **Minimalismo Tonal:** Removemos as bordas físicas! Agora, a hierarquia visual é definida por mudanças suaves de tons de bege e branco (`SurfaceContainer`), criando uma interface limpa e premium.
- **Tipografia de Autoridade:** Nova escala tipográfica com alto contraste e tracking ajustado para um visual de "revista premium".
- **Identidade Visual Premium:** Paleta de cores refinada com o novo Vermelho Terra (`#A20513`) para ações críticas e Bege Light (`#FDF9F4`) como base tátil.
- **Geometria Cangaceira:** Containers agora utilizam curvaturas acentuadas (24dp) inspiradas na silhueta do Chapéu de Cangaceiro.

### 🔐 Login Unificado e Segurança
- **Identificação Automática:** O app agora diferencia Gerentes e Clientes automaticamente através de E-mail ou Telefone.
- **Campos Mandatórios:** E-mail e Telefone tornaram-se obrigatórios no cadastro para garantir a unicidade do acesso.
- **Validação e Máscaras:** Adicionada validação de e-mail e máscara dinâmica de telefone `(XX) XXXXX-XXXX`.

### ✨ Melhorias Técnicas
- **Consistência de Nomenclatura:** Finalizada a migração global de termos para **"Cliente"**.
- **Performance:** Otimização do fluxo de estados no Compose para uma navegação mais fluida.
