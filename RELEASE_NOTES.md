# Release Notes — XuxuBank v1.3.0 🌵💰

Esta é uma atualização histórica: o XuxuBank agora está na nuvem! Migramos toda a nossa infraestrutura para o **Firebase Firestore**, permitindo sincronização em tempo real e acesso multi-dispositivo.

## 🚀 O que há de novo

### ☁️ Cloud Firestore Integration
- **Dados em Tempo Real:** Agora, qualquer alteração feita pelo gerente (como baixar uma dívida ou cadastrar um cliente) é refletida instantaneamente para o cliente e vice-versa.
- **Arquitetura Escalável:** Saímos dos IDs numéricos sequenciais para identificadores globais únicos (String), preparando o app para milhões de usuários.
- **Conectividade:** O app agora é capaz de persistir dados na nuvem com segurança e performance.

### 🔐 Segurança e Acesso
- **Sessões Remotas:** As sessões de login agora são gerenciadas na nuvem, garantindo que sua identidade seja preservada.
