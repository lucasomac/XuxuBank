# Release Notes - XuxuBank v1.0.0

## 🌵 Overview
XuxuBank is a modern, regionalized debt management application designed for the XuxuCorp universe. It combines advanced financial tracking with a vibrant visual identity inspired by Northeast Brazil.

## 🚀 Key Features
- **Client & Debt Management:** Full CRUD operations for managing clients and their individual debts.
- **Smart Installment Logic:** Automatically split large amounts into monthly installments with calculated due dates.
- **Role-Based Access Control (RBAC):** Distinct experiences for Managers (administrative) and Clients (view-only personal debts).
- **Filtered Monthly Dashboard:** Grouped financial overview with real-time status filtering (Pending, Paid, Overdue).
- **Adaptive UI:** Responsive List-Detail layout using Material 3 Adaptive, optimized for both phones and tablets.
- **Branded Experience:** Regionalized iconography (Chapéu de Cangaceiro, Chuchu) and an animated splash screen.

## 🛠 Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** Clean Architecture (Domain, Data, UI) + MVVM
- **Dependency Injection:** Koin
- **Local Persistence:** Room Database
- **Navigation:** Jetpack Navigation 3 (State-driven)
- **Adaptive Library:** Compose Material 3 Adaptive

## 🎨 Regional Identity
- **Palette:** Earthy tones including Sun Yellow (`#FDB813`), Earth Red (`#C62828`), and Dry Earth (`#B8860B`).
- **Iconography:** Custom adaptive app icon featuring the *chapéu de cangaceiro* and *chuchu* vegetable.
- **Localization:** Fully localized in **Portuguese (Brazil)**.
